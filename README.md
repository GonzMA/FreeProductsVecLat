# Free products of vector and Banach lattices

Lean 4 formalization accompanying **Free Products of Vector and Banach Lattices**
by Gonzalo Martínez-Fernández and Pedro Tradacete.

The project develops free products (coproducts) of real vector lattices, Archimedean vector lattices, and Banach lattices. It studies how these constructions preserve embeddings, how the vector lattice and Banach lattice free products are related, and provides an analysis of injectivity with respect to vector lattices with a countable number of prime ideals.

The main developments are:

- **Free products and amalgamation:** existence, quotient and pushout constructions, and preservation of injective lattice homomorphisms.
- **Archimedean free products and projectivity:** a characterization of the finitely generated factors whose ordinary free products remain Archimedean, using Baker–Beynon duality, polyhedral cones, and projectivity.
- **Comparison with Banach lattice free products:** the Archimedean vector lattice free product embeds as the sublattice generated by the factors; its completion under the maximal compatible lattice norm is the Banach free product. Further results establish order density, regularity, and preservation of injectivity.
- **Countable prime spectra:** cardinal bounds, lattices of universal disposition, relative injectivity of ordered ultrapowers, and obstructions for Archimedean targets.

Concrete counterexamples accompany these results. Supporting constructions include the topological join representation for continuous-function factors and the tensor products used in the embedding arguments.

## Build and use

Install [elan](https://github.com/leanprover/elan), Git, and Python 3, then run:

```sh
git clone https://github.com/GonzMA/FreeProductsVecLat.git
cd FreeProductsVecLat
lake exe cache get
lake build
python3 scripts/audit_source.py --check
lake env lean scripts/ProofAudit.lean
```

The toolchain is pinned
to **Lean 4.35.0** in [lean-toolchain](lean-toolchain).
[lakefile.toml](lakefile.toml) pins the public
[BanLat library](https://github.com/davidmunozlahoz/banlat), and
[lake-manifest.json](lake-manifest.json) records Mathlib and the other dependency
revisions.

Import the entire development with:

```lean
import FreeProducts
```

`FreeProducts.lean` is the single file collecting all mathematical imports.
For a narrower import, use an individual module, for example:

```lean
import FreeProducts.Consequences.NormAndCompletion
import FreeProducts.CountableSpectra.OrderedExtension
```

## Proof status and checks

The mathematical sources contain **zero explicit proof placeholders** across
50 mathematical modules. The root [FreeProducts.lean](FreeProducts.lean) imports
these modules directly. The separate generated
[ProofAudit.lean](scripts/ProofAudit.lean) checks the transitive axiom
dependencies of **97 registered declarations**, including their private helpers.
It permits only Lean's standard `propext`, `Classical.choice`, and `Quot.sound`;
it rejects `sorryAx` and other axioms for these targets. The tracked-target list
is empty.

`lake build` compiles the mathematical library.
`lake env lean scripts/ProofAudit.lean` runs the axiom audit against the built
library as a separate check; it is not part of the public imports or the default
build. `python3 scripts/audit_source.py --check` verifies the generated root
imports, source inventory, and audit module. The
[CI workflow](.github/workflows/lean.yml) runs these checks, with the axiom audit
after the build, on pull requests and pushes to `main`. Compilation and axiom
checking establish the formal proofs; correspondence with the paper also
requires reviewing the statements and their definitions.

The [source inventory](FORMALIZATION.md) records the mathematical modules.
[PROOF_PROGRESS.md](PROOF_PROGRESS.md) records ancillary work, including two
unfinished Banach-lattice statements removed from the sources; they are not
numbered results of the manuscript covered above. The older
[DraftCoverageAudit.txt](FreeProducts/DraftCoverageAudit.txt) is a historical
comparison against a separate PDF and includes obsolete source locations and
proof-status notes.

After changing mathematical sources or audit targets, regenerate and check with:

```sh
python3 scripts/audit_source.py
lake build
lake env lean scripts/ProofAudit.lean
python3 scripts/audit_source.py --check
```

The registry is maintained in [scripts/audit_targets.json](scripts/audit_targets.json).

equivalences, including the principal-ideal presentation.
`VectorLattice.isFinitelyPresented_iff_principal_quotient` also gives the
presentation equivalence without assuming Archimedeanity. The coproduct
equivalence reuses this classical theory. On cone models, agreement of the
coproducts means equality between the factor-relation ideal and the vanishing
ideal of the product cone. A polyhedral factor ensures this equality for every
closed-cone partner.

The join proof follows the character-space argument in
[Free Products of Banach Lattices, Theorem 6.2](https://arxiv.org/html/2605.28988v1).
`joinCharacterHomeomorph` identifies normalized scalar lattice homomorphisms,
with their pointwise topology, with the join. The inverse extends weighted
point evaluations. The proof of `exists_join_equiv` transports continuous
functions through this homeomorphism and uses
`OrderIdeal.principalKakutaniEquiv` for the complete principal ideal generated
by the distinguished unit.

The abstract Archimedean tensor interface permits arbitrary Archimedean
factors. Its concrete existence construction currently requires Banach factors,
while its universal property allows arbitrary Archimedean targets. Extending
the construction to arbitrary factors requires a general nonvanishing
bimorphism model and a replacement for the use of complete principal ideals.
The scalar factorization lemmas already apply to arbitrary vector lattices.
The auxiliary operator completion and the final projective tensor completion
are separate spaces.
